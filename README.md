# Projeto F

Plataforma experimental para a comunidade de mulheres no desporto, Academia e histórias de atletas.

Fase atual: desenvolvimento e validação não comercial, custo de infraestrutura 0 €.

O projeto não está ainda preparado para inscrições públicas. A configuração do Supabase e as verificações de privacidade e moderação são necessárias antes da abertura.

O código desta aplicação é independente do 24SM.
